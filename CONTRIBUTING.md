## Types of Contributions Welcome

| Type | Examples |
|------|----------|
| 🐛 Bug fixes | Notebook errors, broken paths |
| 📝 Documentation | Typos, clearer explanations, translations |
| 🧪 New analyses | Additional ADMET properties, new docking targets |
| 🎨 Visualization | Better plots, interactive widgets |
| ⚡ Performance | Faster docking scripts, parallel processing |

## Code Style

- **Python**: PEP 8, max line length 100
- **Notebooks**: Clear markdown headers, commented code cells
- **Commit messages**: Use [Conventional Commits](https://www.conventionalcommits.org/)
  -  new features
  -  bug fixes
  -  documentation
  -  code restructuring
