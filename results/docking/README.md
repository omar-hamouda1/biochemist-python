# Docking Results

The authoritative standardized docking outputs are **not** generated by Notebook 14.

Use:

```bash
python -m scripts.run_standardized_docking
python -m scripts.audit_docking --check-artifacts
```

The authoritative report is:

`docking/results/standardized_affinities.csv`

The tracked run provenance is:

`docking/results/standardized_provenance.json`

Historical notebook outputs may remain elsewhere for educational purposes, but they are not the current screening ranking.
